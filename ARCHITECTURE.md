# ARCHITECTURE — MTG Commander deck site

Static site (GitHub Pages, `docs/` folder) that shows our Commander decks: full card list with
Scryfall illustrations, pedagogical statistics (Catalan UI) and the Spanish `.md` guide.
Data is pre-generated by a stdlib-only Python build. Three agents work from this document in
parallel (programmer, test writer, validator); everything below is normative.

Repository root: `/home/ivan/Projects/mtg-deck-summary` (called `ROOT`). Python 3.13 stdlib only.
No Node. Tests: `unittest`. Preview: `python3 -m http.server -d docs 8000`.

## 2. Python public API — `tools/build_site.py`

Single file, stdlib only (`re, json, os, sys, html, unicodedata, dataclasses, pathlib, datetime,
xml.etree.ElementTree`). Run as `python3 tools/build_site.py` from `ROOT` (it computes ROOT as
`Path(__file__).resolve().parent.parent`, so cwd does not matter). Tests import it with
`sys.path.insert(0, str(ROOT / "tools")); import build_site`.

Module constants (public, tests may read them):

```python
ROOT: Path                      # repo root
DECKS_DIR = ROOT / "decks"
DOCS_DIR = ROOT / "docs"
DATA_DIR = DOCS_DIR / "data"
CACHE_FILE = DECKS_DIR / "_cache" / "cards.json"
OWNERS_FILE = DECKS_DIR / "owners.json"
MARK_START = "<!-- cards:start -->"
MARK_END = "<!-- cards:end -->"
TYPE_ORDER = ["Creature", "Planeswalker", "Battle", "Instant", "Sorcery",
              "Artifact", "Enchantment", "Land", "Other"]
TYPE_PRECEDENCE = ["Land", "Creature", "Planeswalker", "Battle", "Instant",
                   "Sorcery", "Artifact", "Enchantment"]
COLORS = ["W", "U", "B", "R", "G"]
BASIC_LANDS = {"Plains", "Island", "Swamp", "Mountain", "Forest",
```

### 2.1 `slugify(name: str) -> str`

NFKD-normalize, drop combining marks, lowercase, replace every run of characters that are not
`[a-z0-9]` with `-`, strip leading/trailing `-`. Examples (these are the 5 deck slugs):

| input (dek basename) | slug |
|---|---|
| `Ms_Bumbleflower` | `ms-bumbleflower` |
| `Edgar_Markov_-_Vampire_Tribal` | `edgar-markov-vampire-tribal` |
| `Krenko_Mob_Boss_Goblin_Combos` | `krenko-mob-boss-goblin-combos` |
| `_Meren_of_Clan_Nel_Toth_EAT_PRAY_KILL` | `meren-of-clan-nel-toth-eat-pray-kill` |
| `Sauron_the_Dark_Lord_` | `sauron-the-dark-lord` |
| `Nazgûl` | `nazgul` |

Also used for section ids (`### 1. Vito, Thorn...` -> `1-vito-thorn-of-the-dusk-rose-bloodthirsty-conqueror-drenaje-infinito-win`).

### 2.2 `parse_dek(path) -> DeckList`

```python
@dataclass
class DeckEntry:  name: str; qty: int; sideboard: bool
@dataclass
class DeckList:   commander: str; cards: list[DeckEntry]   # cards = ALL entries incl. commander
    def total(self) -> int   # sum of qty over all entries (commander included) -> 100
```

Parse with `xml.etree.ElementTree` (entities `&apos;`, `&amp;` are decoded by the parser).
Iterate `<Cards>` elements in document order; `Quantity` -> int, `Sideboard="true"` -> commander.
Every `Sideboard="true"` entry is a commander (partners): they are flagged `sideboard=True`,
moved to the front of `cards` in file order and listed in `DeckList.commanders`;
`DeckList.commander` is the first of them.
Exactly one sideboard entry is expected; zero -> `BuildError`; more than one -> the first one is the
commander, the rest are kept as normal entries. If the same name appears twice, entries are
merged (qty summed, first position kept). The commander entry is moved to index 0 of `cards`.

### 2.3 `primary_type(type_line: str) -> str`

Input like `"Legendary Artifact Creature — Golem"`, `"Sorcery // Land"`, `"Enchantment Land — Urza's Saga"`.
Steps: take the text before the first `" // "` (front face only); take the text before `" — "`;
split into words; return the first entry of `TYPE_PRECEDENCE` that appears in those words;
otherwise `"Other"`. Consequences: artifact creature -> `Creature`; enchantment creature ->
`Creature`; artifact land / enchantment land -> `Land`; `Sorcery // Land` (MDFC) -> `Sorcery`;
`Land // Land` (Pathway) -> `Land`; `Kindred Artifact` -> `Artifact`; `Battle — Siege // Artifact` -> `Battle`.

### 2.4 `card_summary(obj: dict) -> dict`

Trims a Scryfall object to the card schema of §3.3 (without `qty` / `is_commander`, which
`build_deck` adds). Rules for fields that may be absent at top level (transform / modal_dfc):

* `faces_src = obj.get("card_faces") or []`; `front = faces_src[0] if faces_src else {}`.
* `mana_cost = obj.get("mana_cost") or front.get("mana_cost") or ""`.
* `oracle_text = obj.get("oracle_text") or front.get("oracle_text") or ""`.
* `colors = obj.get("colors") if "colors" in obj else front.get("colors", [])`, sorted in WUBRG order.
* `color_identity` sorted in WUBRG order (`sorted(x, key=COLORS.index)`).
* `power, toughness, loyalty`: top level, else `front`, else `None`. Keep as strings (`"*"`, `"0"`).
* `images = pick_images(obj.get("image_uris") or front.get("image_uris") or {})` where
  `pick_images(d)` returns `{k: d.get(k) for k in ("small","normal","large","png","art_crop")}`.
* `faces`: if `faces_src` is non-empty AND `faces_src[0]` has `image_uris`, then a list with one
  entry per face: `{name, mana_cost, type_line, oracle_text, power, toughness, loyalty, colors, images}`
  (missing -> `""`/`None`/`[]`); else `None`. (Split/adventure/prepare cards have one image -> `None`.)
* `price_eur`: `float(obj["prices"]["eur"])` if present and not `None`, else `None`.
* `cmc = int(obj.get("cmc", 0))` (Scryfall gives floats; all deck cards are integral).
* `keywords = obj.get("keywords", [])`, `game_changer = bool(obj.get("game_changer", False))`.
* `set = obj["set"]` (code), `set_name`, `collector_number`, `rarity`, `artist` (default `""`),
  `scryfall_uri`, `type_line`, `name` (`obj["name"]`, which for DFC is `"A // B"`; the deck-facing
  name is set by `build_deck`, see §2.7), `layout`.
* `primary_type = primary_type(type_line)`.

### 2.5 Markdown -> HTML: `md_to_html(text: str, known_names: list[str] | None = None) -> str`

Mini converter for the subset used in `decks/*.md`. Output must be deterministic and
HTML-escaped. Block rules, processed line by line on `text.split("\n")`:

1. **Gallery blocks**: from a line equal to `MARK_START` up to and including the line equal to
   `MARK_END`: collect every `alt="..."` of `<img>` tags inside (`html.unescape`), dedupe keeping
   order, emit `<div class="card-gallery" data-cards="A|B|C"></div>` (names joined with `|`,
   attribute-escaped with `html.escape(quote=True)`). JS renders the images (§5.7). Empty -> emit nothing.
2. **Other raw HTML blocks**: a line starting with `<` (and not a gallery marker) starts a raw block
   that ends at the first blank line; passed through verbatim.
3. **Headings**: `^(#{1,6}) (.+)$` -> `<hN id="{slugify(text)}">{inline(text)}</hN>`.
4. **Blockquote**: consecutive lines starting with `>`; strip `> ?`; join with `\n`; emit
   `<blockquote><p>{inline(joined)}</p></blockquote>`.
5. **Tables**: a line starting with `|` whose next line matches `^\|?\s*:?-{3,}` starts a table.
   Header row -> `<thead><tr><th>…</th></tr></thead>`, following `|`-lines -> `<tbody>` rows.
   Cells split on `|` after stripping the outer pipes, each `.strip()` and `inline()`-processed.
   Emit `<table class="md-table">`. Ends at first line not starting with `|`.
6. **Lists**: lines matching `^(\s*)([-*]|\d+\.) (.*)$`. Indent = number of leading spaces; a nested
   level opens when indent increases (any increase >= 2 spaces), closes when it decreases.
   `-`/`*` -> `<ul>`, `\d+.` -> `<ol>`. Items emitted as `<li>{inline(text)}</li>`; nested lists are
   placed inside the parent `<li>` before its `</li>`. A list ends at a blank line or a
   non-list line. (No lazy continuation lines are required.)
7. **Paragraphs**: any other consecutive non-blank lines are joined with a space and emitted as
   `<p>{inline(text)}</p>`.
8. Horizontal rule `---` (alone on a line, not in a table) -> `<hr>`.

`inline(s)` rules, in this order:

a. Extract inline code `` `x` `` into placeholders (`\x00N\x00`), rendered as `<code>{escaped}</code>` at the end.
b. `html.escape(s, quote=False)` (apostrophes stay `'`, so card names keep matching).
c. `**x**` -> `<strong>x</strong>`; then `*x*` and `_x_` (word-bounded) -> `<em>x</em>`.
d. `[text](url)` -> `<a href="url" target="_blank" rel="noopener">text</a>`.
e. Card references (§2.6) applied only to text outside tags: split on `(<[^>]+>)`, transform the
   even segments, rejoin.
f. Restore code placeholders.

### 2.6 Card-name matching — `find_card_refs` / `wrap_card_refs`

```python
def aliases(names: list[str]) -> dict[str, str]
def find_names(text: str, names: list[str]) -> list[str]
def wrap_card_refs(escaped_text: str, names: list[str]) -> str
```

`aliases` and `find_names` reproduce `decks/add_images.py` exactly:

* `aliases`: for each name containing `", "`, `short = name.split(", ")[0]`; it is an alias iff no
  OTHER name in `names` `startswith(short)` and `short` not already taken. E.g.
  `"Vito"` -> `"Vito, Thorn of the Dusk Rose"`, `"Narset"` -> `"Narset, Parter of Veils"`.
  Only `startswith` clashes count: `"Loki"` IS an alias of `"Loki, God of Mischief"` even when
  `"Kid Loki"` exists (it does not start with `"Loki"`), whereas `"Edgar"` is NOT an alias of
  `"Edgar, Charmed Groom"` because `"Edgar Markov"` starts with `"Edgar"`.
* Matching regex for a candidate `n`: `(?<![\w'])` + `re.escape(n)` + `(?![\w])`. Full names are
  tried longest first; each match is blanked out (replaced by spaces) before trying shorter names,
  so `"Goblin Chieftain"` does not also match `"Goblin"` inside it. Aliases are tried afterwards and
  only if their full name was not already found.
* `find_names` returns the list of full names ordered by first occurrence (deduped).
* `wrap_card_refs` uses the same regexes on the HTML-escaped text and wraps EVERY occurrence
  (full names longest first, then aliases) as
  `<span class="card-ref" data-card="{attr-escaped full name}">{matched text}</span>`. To avoid
  double wrapping, matching is done on the text with previously wrapped spans protected by
  placeholders (same `\x00N\x00` technique). The comparison text for matching is the escaped
  name: `html.escape(name, quote=False)` (matters for `&`).
* Card refs are applied inside headings (levels 2-6), paragraphs, list items, table cells and
  blockquotes, but NOT to the H1 and NOT inside `<code>`.

### 2.7 `parse_md(text: str, known_names: list[str] | None = None) -> dict`

```python
{
  "title": "Ms. Bumbleflower",          # H1 text with the trailing "(...)" removed, stripped
  "subtitle": "Bant: G/W/U",            # content of the LAST "(...)" group of the H1, or ""
  "bracket": 4,                         # int from r"Bracket\s*(\d)" in the first blockquote, or None
  "bracket_text": "Bracket 4. Lista original de deckstats (`Ms_Bumbleflower.dek`).",  # raw blockquote text (markdown, `>` stripped) or ""
  "intro_html": "",                     # html of everything after the blockquote and before the first "##", galleries EXCLUDED
  "sections": [                         # flat, document order, only "##" and "###"
    { "level": 2, "id": "idea-general", "heading": "Idea general",
      "heading_html": "Idea general",            # inline-processed (card refs allowed)
      "html": "<p>…</p><ul>…</ul>",              # body html until next heading of level <= 3, galleries included as <div class="card-gallery">
      "gallery": ["Whitemane Lion", …],          # union of gallery card names in this section, order kept
      "cards": ["Whitemane Lion", …] },          # find_names(heading + body text without galleries), order of appearance
    …
  ],
  "card_refs": ["…"]                    # union of sections[*].cards, order of first appearance
}
```

Heading ids: `slugify(heading)`; if duplicated, append `-2`, `-3`… Headings deeper than `###`
are folded into the current section's `html`. The H1 is not a section. `known_names` defaults to
`[]` (then `cards`/`card_refs` are empty and no spans are produced).

### 2.8 `compute_stats(cards: list[dict], commander_name: str) -> dict`

`cards` are §3.3 card entries (with `qty` and `is_commander`). The commander is counted
everywhere exactly like any other card (it is card 100 of 100). Every count is weighted by `qty`.
"Non-land" means `primary_type != "Land"`. Returns the exact object of §3.4. Details:

* `mana_curve`: keys `"0".."6"` and `"7+"`, always all present; non-land only; bucket = `min(cmc, 7)`.
* `avg_mana_value`: `round(sum(cmc*qty) / sum(qty), 2)` over non-land; `0.0` if none.
* `pips`: parse only the part of `mana_cost` before `" // "`; symbols = `re.findall(r"\{([^}]+)\}")`.
  Symbol `s`: in WUBRG -> `pips[s] += qty`; `"C"` -> `pips["C"] += qty`; all digits ->
  `generic += int(s)*qty`; contains `/` -> for each part in WUBRG add `qty` (hybrid `W/U` counts W
  and U; phyrexian `G/P` counts G; `2/W` counts W); anything else (`X`, `S`, `T`, …) ignored.
  Non-land cards only.
* `color_identity`: union of every card's `color_identity`, in WUBRG order.
* `cards_by_color` (non-land): `len(colors)==0` -> `colorless`; `==1` -> that color; `>1` -> `multicolor`.
* `mana_sources`: `lands_total` = qty of Land cards; `lands_colored` = lands whose
  `produced_mana` (see §3.3) contains at least one of WUBRG; `nonland_producers` = non-land
  cards with non-empty `produced_mana`; `by_color[c]` = qty of ANY card (land or not) whose
  `produced_mana` contains `c` (`C` too).
* `rarity`: keys `common, uncommon, rare, mythic` always present (0 default) plus any other
  Scryfall rarity encountered (`special`, `bonus`).
* `price_eur`: `total = round(sum(price*qty for priced), 2)`; `priced_cards`/`unpriced_cards`
  count qty; `most_expensive` = top 5 distinct cards by `price_eur` desc then name, each
  `{name, price_eur}`.
* `keywords`: top 10 `{keyword, count}` (count = qty-weighted number of cards having it), sorted
  by count desc then keyword asc.
* `game_changers`: names of cards with `game_changer == true`, sorted.
* `by_type`: every key of `TYPE_ORDER` present (0 default).

### 2.8b `find_deks(decks_dir) -> list[Path]`

Loose `decks/*.dek` plus `decks/<Owner>/*.dek` for every non-reserved, non-hidden folder,
sorted by (folder name, file name), case-insensitively.

### 2.9 `build_deck(dek_path, md_path, cards_cache: dict, owners: dict, taxonomy=None, roles_path=None, decks_dir=None) -> dict`

Returns the §3.2 object. `md_path` may be `None` (then `guide` is `None`, `title` = dek basename
with `_` -> space, collapsed spaces, stripped; `subtitle` `""`, `bracket` `None`).
Card lookup: `cards_cache[entry.name]`; missing -> `MissingCardError`. The card entry's `name`
is `entry.name` (the deck-facing front name, e.g. `"Agadeem's Awakening"`), and
`full_name` is the Scryfall `name` (`"Agadeem's Awakening // Agadeem, the Undercrypt"`).
`produced_mana` is copied from the Scryfall object (`[]` if absent/None).
`known_names` for the guide = all deck names except basic lands (as in `add_images.deck_names`),
INCLUDING the commander. `commander` in the output is the full card entry (same dict as in `cards[0]`).
Owner: `deck_owner(dek_path, owners, decks_dir)` (§1.1). `roles_path` defaults to
`<dek folder>/roles/<basename>.json` and, when that file does not exist and `decks_dir` is
given, to `decks/roles/<basename>.json`.

### 2.10 `build_all(root: Path | None = None) -> dict`

Loads cache and owners; for every `.dek` returned by `find_deks(decks_dir)`, pairs with the
sibling `<same>.md` if
present; writes `docs/data/decks/<slug>.json` and `docs/data/index.json` (`json.dump(...,
ensure_ascii=False, indent=1, sort_keys=True)` + trailing newline); deletes stale
`docs/data/decks/*.json` not produced in this run; creates dirs and `docs/.nojekyll`; prints one
line per deck (`OK <slug> 100 cards`). Returns the index object. `main()` calls it and exits 1
with the message on `BuildError`. Slug collisions -> `BuildError`.

`build_index(decks: list[dict]) -> dict` is the pure function that derives §3.1 from deck objects.

## 4. Front-end architecture

`docs/index.html`: `<html lang="ca">`, viewport meta, `<title>`, links `css/base.css` and
`css/components.css`, preconnect to `https://cards.scryfall.io` and `https://svgs.scryfall.io`,
Google Fonts link (§9), body skeleton:

```html
<header class="site-header"><a href="#/" class="brand">…</a><nav id="crumbs"></nav></header>
<main id="app" aria-live="polite"></main>
<footer class="site-footer"></footer>
<div id="preview" hidden></div>
<div id="lightbox" hidden></div>
<script type="module" src="js/app.js"></script>
```

All paths relative (no leading `/`) so the site works under `https://user.github.io/repo/`.

### 4.1 `js/data.js`

```js
export class DataError extends Error { constructor(message, {url, status}) }
export async function loadIndex()          // GET data/index.json, cached after first success
export async function loadDeck(slug)       // GET data/decks/<slug>.json, cached; throws DataError (status 404 -> not found)
export function clearCache()
```

`fetch` with `{cache: "no-cache"}`; non-OK -> `DataError`; JSON parse errors -> `DataError`.

### 4.2 `js/app.js` — router

Routes (hash based, `hashchange` + initial load):

| hash | view | document.title |
|---|---|---|
| `#/` or empty | `views/home.js` `renderHome(root, index)` | `t("app.title")` |
| `#/deck/<slug>` | `views/deck.js` `renderDeck(root, deck, {tab: "list"})` | `${deck.title} · ${t("app.title")}` |
| `#/deck/<slug>/stats` | same view, stats tab active | |
| `#/deck/<slug>/guia` | `views/guide.js` `renderGuide(root, deck)` | `${deck.title} · ${t("nav.guide")}` |
| `#/deck/<slug>/guia/<section-id>` | guide, then `scrollIntoView` on `#<section-id>` | |
| anything else | `renderNotFound(root)` | |

Flow for every route: `root.innerHTML = loadingView()` (spinner + `t("state.loading")`), then
await data, render, or `renderError(root, err, retryFn)` on failure (`t("state.error.title")`,
`t("state.error.body", {what})`, a retry button and a link home). Deck 404 -> message
`t("state.deckNotFound")`. `app.js` also fills breadcrumbs (`Inici › Deck title › Guia`) and the
footer text, closes any open lightbox/preview on route change, and scrolls to top unless a section
anchor is given. Each view exports a single `render*(root, …)` function that replaces `root`'s
content and attaches its own listeners (use event delegation on the view root).

## 5. Views and behaviors

### 5.1 Home (`views/home.js`)

Header: `t("app.title")` + `t("home.subtitle")`. Owner filter (shown whenever there is at least
one owner): a `.chip-group` with `t("home.filter.owner")` as label, a `t("home.filter.all")` chip
and one chip per `index.owners` entry that owns a deck, each with its deck count in
`.chip-count`; the active chip carries `aria-pressed="true"`. Client-side filter, no URL state;
the choice is kept in `sessionStorage["mtg.owner"]` so it survives visiting a deck and coming
back (an unknown owner falls back to "all").
Grid of deck cards (`.deck-card`, `<a href="#/deck/<slug>">`): commander `art_crop` as a
16:9-ish banner (`aspect-ratio: 4/3`, `object-fit: cover`, `loading="lazy"`), title, subtitle
(muted), color identity pips (`pipsHtml(color_identity)`; empty identity -> the `C` symbol), meta
row: `t("home.cards", {n})` · `t("home.bracket", {n})` (omit if null) · owner nickname badge.
Empty list -> `t("home.empty")`.

### 5.2 Deck view (`views/deck.js`)

Layout: hero banner (commander `art_crop` blurred/darkened as background, title, subtitle, pips,
owner, bracket, `t("home.cards")`), tab bar with three links: `t("deck.tab.list")`
(`#/deck/<slug>`), `t("deck.tab.stats")` (`#/deck/<slug>/stats`), `t("deck.tab.guide")`
(`#/deck/<slug>/guia`, disabled with tooltip `t("guide.missing")` when `guide === null`).

**List tab.** Toolbar: search input (placeholder `t("deck.search.placeholder")`), type chips
(`t("deck.filter.all")` + one chip per `primary_type` present, in `TYPE_ORDER`; single-select),
color chips `W U B R G C` (multi-select, OR semantics; `C` matches `colors.length === 0`), view
toggle (`t("deck.view.grid")` / `t("deck.view.list")`, persisted in `localStorage["mtg.view"]`,
default `grid`), result counter `t("deck.results", {shown, total})` (qty-weighted).
Search: case- and accent-insensitive substring on `name` and `full_name`
(`normalize("NFD").replace(/\p{M}/gu, "")`). Filters are combined with AND. No matches ->
`t("deck.noresults")`. Filters reset when the deck changes.

Grouping (both grid and list): group `Comandant` first (only `is_commander` cards), then one
group per `primary_type` in `TYPE_ORDER` order, skipping empty groups and excluding the
commander from its type group. Group heading: `t("type.<Type>")` + count in parentheses
(qty-weighted). Within a group sort by `cmc` asc, then `name` (`localeCompare("en")`).

Grid item (`.card-tile`, `button` element for accessibility): `<img src=images.normal
loading="lazy" alt=name>` inside a 63:88 box, `qty` badge when `qty > 1` (`×N`), name caption
below (one line, ellipsis). Missing `images.normal` -> placeholder box with the name.

List item: `<table class="card-table">` columns `t("deck.col.qty")`, `t("deck.col.name")`
(as `.card-ref`), `t("deck.col.cost")` (`manaHtml`), `t("deck.col.type")`, `t("deck.col.price")`
(`price_eur` formatted `12,34 €` with `Intl.NumberFormat("ca-ES", {style:"currency", currency:"EUR"})`, or `—`).

Click on a tile or a `.card-ref` -> `openLightbox(visibleCards, index)` where `visibleCards` is the
flattened, filtered, grouped+sorted list currently displayed.

**Stats tab** (`components/stats.js` `renderStats(container, stats, t)`): one `.stat-block` per
statistic, in this order: `total`, `types`, `curve`, `avg`, `identity`, `pips`, `colors`,
`sources`, `rarity`, `price`, `keywords`, `gamechangers`. Each block: `<h3>` = `t("stats.X.title")`,
the visualization, then a `<details class="stat-help">` opened by default on desktop (>= 900px)
and collapsed on mobile, with two labelled paragraphs: `t("stats.help.what")` +
`t("stats.X.what")`, `t("stats.help.why")` + `t("stats.X.why")`.
Visualizations (pure HTML/CSS bars, `role="img"` + `aria-label` with the numbers):
* `total`: big number `100` + `land_count` / `nonland_count` sub-figures.
* `types`: horizontal bars, one per type in `TYPE_ORDER` with count > 0.
* `curve`: vertical bars `0…7+`, value labels on top, average marked as text.
* `avg`: big number with 2 decimals (comma as decimal separator).
* `identity`: pips (large) + color names.
* `pips`: horizontal bars per color W U B R G (+ C if > 0) using the color palette of §9, and a
  note `generic`.
* `colors`: horizontal bars incl. multicolor (gold) and colorless (grey).
* `sources`: three numbers (`lands_total`, `lands_colored`, `nonland_producers`) + per-color bars from `by_color`.
* `rarity`: bars (common grey, uncommon silver, rare gold, mythic orange).
* `price`: big number total + `priced/unpriced` + list of `most_expensive` as `.card-ref`s.
* `keywords`: chip list `Keyword ×count`.
* `gamechangers`: list of `.card-ref`s, or `t("stats.gamechangers.none")`.

### 5.3 Guide view (`views/guide.js`)

Header: commander `art_crop` banner, `guide.title`, `guide.subtitle`, `bracket_text` rendered
through `inlineMd` -> shown as a `<blockquote>` (build already gives `bracket_text` as markdown;
JS converts only backticks to `<code>` and escapes the rest), note `t("guide.language")`, link
back `t("guide.back")` (`#/deck/<slug>`). Sticky TOC (`<nav class="toc">`, `t("guide.toc")`):
`<ol>` of level-2 sections with nested `<ol>` of the following level-3 sections; links to
`#/deck/<slug>/guia/<id>`. Under 900px the TOC becomes a `<details>` above the content.
Body: `intro_html`, then for each section `<section id=id><hN>heading_html</hN>html</section>`
(`hN` = `h2` / `h3`). Rendering `html` is trusted build output (`innerHTML`). After insertion:
* every `.card-gallery` element is filled (§5.7);
* `.md-table` gets wrapped in `<div class="table-scroll">`;
* `.card-ref` elements get hover preview (§5.5) and click -> lightbox (§5.6). A `.card-ref` whose
  `data-card` is not in the deck (should not happen) is rendered as plain text without preview.

Card lookup: `Map(name -> card entry)` built from `deck.cards`.

### 5.4 `.card-ref` elements (everywhere)

`<span class="card-ref" data-card="Name">…</span>`: styled as a subtle link (accent color,
dotted underline), `tabindex="0"`, `role="button"`. Enter/Space = click. Click -> lightbox with
context: in the guide, gallery clicks use the gallery's card list as context; inline refs use
the whole deck list (§5.2 ordering) positioned at that card.

### 5.5 Hover preview (`components/preview.js`)

```js
export function attachPreview(root, resolveCard)   // delegation on mouseover/mouseout/focusin/focusout for .card-ref and .card-tile
export function hidePreview()
```

Only when `matchMedia("(hover: hover) and (pointer: fine)")` matches. After 250 ms of hovering,
show `#preview` (fixed, `pointer-events: none`, 260px wide image `images.normal`, with fallback
to `images.large`) positioned next to the element (right side, flipped to the left if it would
overflow, clamped vertically to the viewport). Grid tiles do NOT show the floating preview (they
already enlarge on hover via CSS `transform: scale(1.06)`), only `.card-ref` and list rows do.
Hidden on `mouseout`, scroll, Escape, and route change.

### 5.6 Lightbox (`components/lightbox.js`)

```js
export function openLightbox(cards, index)   // cards: array of card entries; index: start position
export function closeLightbox()
export function isOpen()
```

Fills `#lightbox` (`role="dialog" aria-modal="true" aria-label=name`), locks body scroll
(`body.classList.add("no-scroll")`), stores the previously focused element and focuses the close
button; on close restores focus. Layout: two columns on >= 900px (image left, details right),
stacked (image on top, max-height 60vh) below. Image: `images.png`, fallback `large`, then
`normal`; `alt` = name; `decoding="async"`; a spinner is shown until `load`. Details panel:
name (h2), `manaHtml(mana_cost)`, `type_line`, oracle text (`oracleHtml`, `\n` -> `<br>`),
P/T (`t("lightbox.pt")`: `3/3`) or loyalty (`t("lightbox.loyalty")`), set line
`set_name (SET) #collector_number`, rarity (`t("rarity.<x>")`), artist (`t("lightbox.artist")`),
price (`t("lightbox.price")`, or `t("lightbox.noprice")`), `qty` if > 1, Scryfall link
(`t("lightbox.scryfall")`, `target="_blank" rel="noopener"`). If `faces` is non-null: a
`t("lightbox.flip")` button toggles the shown face (image + name/mana/type/oracle/P/T from the
face); face index resets to 0 on navigation.
Controls: prev/next buttons (`t("lightbox.prev")`, `t("lightbox.next")`, hidden when
`cards.length === 1`, wrap around), counter `t("lightbox.counter", {i, n})`, close button.
Keyboard: `ArrowLeft`/`ArrowRight` navigate, `Escape` closes, `Tab` is trapped inside the dialog.
Click on the backdrop closes. Images of the next and previous card are preloaded (`new Image()`).

### 5.7 Galleries in the guide

For each `<div class="card-gallery" data-cards="A|B">`: split on `|`, resolve each name via the
deck map, replace the div's content with `<figure class="gallery-item">` per card:
`<button class="card-tile"><img src=images.normal loading="lazy" alt=name></button>
<figcaption>name</figcaption>`. Unknown names are skipped. Gallery grid uses the same tile sizes
as the deck grid (§9). Click -> lightbox with the gallery list as context.

### 5.8 Symbols (`components/mana.js`)

```js
export function symbolUrl(sym)          // "W" -> "https://svgs.scryfall.io/card-symbols/W.svg"; "W/U" -> ".../WU.svg"; "G/P" -> ".../GP.svg"; "2/W" -> ".../2W.svg"; "T" -> ".../T.svg"
export function manaHtml(cost)          // "{2}{W}{U} // {X}" -> <span class="mana"><img class="ms" src=… alt="{2}">…<span class="mana-sep">//</span>…</span>; "" -> ""
export function pipsHtml(colors)        // ["W","U"] -> W and U symbols (large class "ms-lg"); [] -> C symbol
export function oracleHtml(text)        // escape text, replace {…} symbols with <img class="ms ms-inline">, "\n" -> "<br>"
```

`symbolUrl` = `https://svgs.scryfall.io/card-symbols/` + `sym.replace("/", "")` + `.svg`.
Every `<img class="ms">` has `alt="{sym}"`, `width="16" height="16"` (18 in oracle text, 22 for `ms-lg`).

## 11. Events — `events/<folder>/` -> `docs/data/events/`

Input: one folder per event holding `event.json` plus `event.<lang>.md` (required per language)
and `set.<lang>.md` (optional set guide). `event.json` keys: `title`, `date` (ISO), `time`
(string or null = TBD), `location` `{name, url}`, `set` (Scryfall set code -> needs
`decks/_cache/sets/<code>.json`, `{"set", "name", "cards": [Scryfall objects]}`), `art_card`
(front-face name of the card whose `art_crop` is the banner/poster), `video` `{src, type, source}`,
`languages` (list, first = default unless `default_lang`), `extra_cards` (names taken from
`cards.json`). Reserved-looking folders (`.`/`_` prefix) are skipped.

Build (`load_set_cache`, `build_event`, `build_events`, called from `build_all`): card names are
matched against the set's front-face names (`"A // B"` -> `"A"`) with `find_names`/`parse_md`;
every card cited or in a gallery is exported as a §3.3 entry (no `qty`/`roles`) under `cards`.
Output `docs/data/events/index.json` = `{generated_at, events: [{slug, title, date, time,
location, set: {code, name}, art, languages, default_lang, file}]}` (newest date first) and
`docs/data/events/<slug>.json` = the index entry plus `video`, `pages: {<lang>: {event, set|null}}`
(each a `parse_md` result without `bracket*`) and `cards: {name: entry}`. Stale files are pruned.

Front-end (`js/views/events.js`, `css/events.css`): routes `#/esdeveniments` (list, Catalan UI,
reuses `.deck-card`), `#/esdeveniments/<slug>` (event page: hero with language toggle, facts
`<dl>`, hotlinked `<video>` with the art as poster, TOC + `.md-content`), `#/esdeveniments/<slug>/edicio`
(set guide) and `/info/<section>` / `/edicio/<section>` anchors. The page chrome of an event is in
the event's language (dictionary `L` in `events.js`, keys `ca`, `es`, `it`); the chosen language is
kept in `localStorage["mtg.eventLang"]`. Card refs, galleries, hover preview and lightbox reuse
the guide helpers (`fillGalleries`, `prepareRefs` exported from `views/guide.js`).
